Bits, bytes & the units built from them

Before getting into how specific numbers are stored, here's the vocabulary the rest of this page builds on: bits, bytes, the decimal-vs-binary prefixes used to measure them, and how the same ideas extend to memory sizes, bandwidth, and clock frequency.

A byte is 8 bits

bita single binary digit: 0 or 1
nibble4 bits — exactly one hexadecimal digit (0–F)
byte8 bits — the smallest addressable unit in C++; sizeof(char) == 1 by definition
wordthe CPU's native register size — 16-bit historically, 32-bit on classic x86, 64-bit on modern x86-64 / ARM64

Frequency & clock period

Frequency and time are reciprocals: a 3 GHz CPU completes one clock cycle roughly every third of a nanosecond.
