if / else if / else

Exactly one branch runs. C++ checks conditions top to bottom and takes the first one that's true; if none are true, the final else (if present) runs.

while vs. do-while

    
Same three ingredients as a for loop — a starting value, a condition, and something that changes it — just written out separately instead of packed into a header. The one real difference: while checks the condition before the first iteration; do‑while checks it after, so the body always runs at least once.

Range-based for

    
No index, no explicit start/end/increment to write — the compiler generates the equivalent of an iterator walk from begin() to end() for you.

Equivalent iterator form: for (auto it = container.begin(); it != container.end(); ++it), using *it where the range-based version uses the loop variable. begin() points at the first element; end() is a sentinel one-past-the-last element — never dereferenced, just used to know when to stop.
